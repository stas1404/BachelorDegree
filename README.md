## Задача расправления изображений (Image Dewarping)

### SOTA-Постановка задачи

Пусть имеется изображение (цветное, с фоном) сдвинутого относительно осей и плоскости камеры текстового документа (со сдвигами, изгибами, помятостями). Нужно получить изображение этого документа, на котором плоскость документа параллельна плоскости камеры, а строки - её осям. 

### Решения

[DocMatcher](https://felixhertlein.github.io/doc-matcher/) - CVPR 2025

[SAM](https://arxiv.org/pdf/2408.00714)
